## 📖 Введение  
Графы — одна из базовых структур данных в программировании. Они находят применение в различных областях:  
- Моделирование дорог  
- Связь в социальных сетях  
- Электрические цепи  

В этом проекте реализована библиотека для работы с графами, включая алгоритмы поиска путей, построения минимального остовного дерева и решения задачи коммивояжера.

---

## 📜 Историческая справка  
Первым шагом к созданию теории графов стало решение задачи о семи мостах Кёнигсберга, которое предложил **Леонард Эйлер** в 1736 году. Это положило начало развитию теории графов, которая активно используется и сегодня.

---

## 📊 Описание графов  
Граф — это совокупность **вершин** и **рёбер**, соединяющих эти вершины.  
В проекте используются следующие виды графов:  
- **Неориентированный граф** — рёбра не имеют направления.  
- **Ориентированный граф** — рёбра имеют направление (дуги).  
- **Взвешенный граф** — рёбра имеют числовой вес.  

---

## ⚙️ Функциональность проекта  
Проект реализует следующие функции:  
- Загрузка графа из файла в формате **матрицы смежности**  
- Экспорт графа в формат **Graphviz (DOT)**  
- Обход графа в **глубину** и **ширину**  
- Поиск **кратчайшего пути**  
- Построение **минимального остовного дерева**  
- Решение **задачи коммивояжера**

**Методы:**

- **BFS (Breadth-First Search)** — обход графа в ширину

### 6.3. Минимальное остовное дерево  
**Методы:**  
- **Алгоритм Крускала**  
- **Алгоритм Прима**  

### 6.4. Задача коммивояжера  
**Методы решения:**  
- **Жадный алгоритм**

## 🖥 Консольный интерфейс  
Приложение предоставляет консольный интерфейс для взаимодействия с пользователем. Основные команды:  
- `load [filename]` — загрузка графа из файла  
- `export [filename]` — экспорт графа в формат DOT  
- `dfs [start_node]` — обход графа в глубину  
- `bfs [start_node]` — обход графа в ширину  
- `shortest_path [start] [end]` — поиск кратчайшего пути
